# 嵌入式（Embedded）实践

嵌入式开发：用单片机控制硬件、采集数据。CodeLab 硬件部的入门方向。

## 平台选择

| 平台 | 适合 | 说明 |
| --- | --- | --- |
| Arduino | 入门、快速原型 | 简单，生态好 |
| ESP32 / ESP8266 | WiFi / 物联网 | 便宜，自带无线 |
| STM32 | 进阶、工业级 | 性能强，资料多 |
| 树莓派 Pico | 微控制器 + MicroPython | 轻量 |

## 开发环境

- **Arduino**：Arduino IDE / PlatformIO（VS Code 插件，推荐）
- **STM32**：STM32CubeIDE 或 PlatformIO + HAL 库
- **ESP32**：PlatformIO + Arduino 框架，或 ESP-IDF

> 实验室统一推荐 **PlatformIO**：一套工具链管所有平台，配置进 git。

## 基本流程

```text
需求（采集什么 / 控制什么）
  ↓ 选型（板子、传感器）
  ↓ 接线 + 测试（先单独验证传感器）
  ↓ 写驱动 / 逻辑
  ↓ 联调（上位机 / 串口）
  ↓ 部署到现场（供电、外壳、固件版本）
```

## 规范要点

- **代码仓库化**：`platformio.ini` 和 `src/` 提交 git，不用 IDE 默认目录
- **串口协议要文档化**：帧格式、波特率、校验写清楚（[接口文档先行](overview.md)）
- **固件版本管理**：版本号 + 变更记录，方便现场排查
- **模块化**：传感器驱动单独文件，不写成一坨
- **异常处理**：传感器读取失败要有重试和错误上报
- **日志**：串口输出结构化日志（时间 + 级别 + 内容）

## 常见坑

- 供电不足：传感器瞬间电流大，用独立供电 / 电容
- 电平不匹配：3.3V 与 5V 器件互连要电平转换
- 浮空引脚：未接的输入引脚要上下拉，避免乱跳
- 烧板：先确认接线、再上电；USB 供电注意限流
